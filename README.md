# Vanity — бесплатные красивые адреса для Telegram Wallet

Бесплатный аналог [vanity.tg](https://vanity.tg). Ищет адрес Telegram Wallet с вашим текстом в конце (`…GRAM`) или в начале (`UQDog…`).
Всё считается в браузере посетителя: на видеокарте через WebGPU или на процессоре. Сервера нет.

## Как это устроено

Telegram Wallet использует контракт [WalletTg](https://github.com/ton-blockchain/tg-wallet-contract), где ключ можно сменить, а адрес остаётся прежним.
Фраза из 24 слов делится на две половины:

| Слова | Откуда | Что делают |
|---|---|---|
| 1–12, anchor | находит поиск | BIP39 → SLIP-10 `m/44'/607'/0'` → ed25519 → stateInit трамплина → **адрес** |
| 13–24, signing | создаёт браузер | новый ключ, на который кошелёк переключается on-chain |

Порядок работы: поиск → запись 24 слов → пополнение адреса (~0.05 GRAM) → одна external-транзакция
(деплой + `ChangePublicKeyRequestE`) → импорт 24 слов в Telegram Wallet.

Скорость не подгоняется под конкретную видеокарту. При открытии сайт:
1. компилирует шейдер и **сверяет GPU с CPU** на 16 случайных фразах (при любом расхождении GPU не используется);
2. делает короткий замер на устройстве посетителя, по нему считает медиану и «1 из 20» для выбранного шаблона;
3. подстраивает размер пачки под ~220 мс, чтобы не упираться в таймаут драйвера.

Ориентиры: RTX 5070 Ti — около 440 тыс. фраз/с (6 символов в любом регистре — около 25 минут),
16 потоков CPU без WebGPU — около 4 тыс. фраз/с.

## Запуск у себя

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5178 в свежем Chrome или Edge (там есть WebGPU).

## Тесты

```bash
npm test
```

- `test/derive.test.js` — быстрый конвейер сверяется с эталоном (@scure/bip39, SLIP-10 из micro-key-producer, @ton/core): ключи, адреса mainnet/testnet, BIP39-чек-сумма, формат сообщения смены ключа.
- `test/sandbox.test.js` — эмулятор @ton/sandbox с **живым байткодом WalletTg** из `config[-123]` (`test/config-123.json`): пополнение → деплой и смена ключа → anchor-ключ больше не подписывает, перевод новым ключом проходит.

GPU-шейдер проверяется в браузере при каждом запуске (самопроверка выше).

## Публикация для всех

```bash
npm run build
```

Получается один файл `dist/index.html`, его можно выложить на любой статический хостинг: Vercel, Netlify, Cloudflare Pages, GitHub Pages.
Нужен HTTPS, иначе браузер не даст WebGPU. В сборку встроен Content-Security-Policy: сеть разрешена только к `toncenter.com` и `testnet.toncenter.com`.

Проверить сборку локально: `npm run preview` → http://127.0.0.1:5179.

## Важно

- Сначала попробуйте короткий шаблон и небольшую сумму. Можно в **testnet** (раздел «Дополнительно»): там WalletTg тоже включён.
- Пока ключ не сменён, первые 12 слов — единственный доступ к адресу. После смены они сами по себе ничего не могут.
- Фразы хранятся в `localStorage` этого браузера. После импорта в Wallet удалите запись кнопкой «Удалить».
- `encryptedOldPrivateKey` в запросе смены ключа заполняется нулями. Контракт его не проверяет. Он нужен только для расшифровки старых зашифрованных сообщений, а у свежего кошелька их нет.
- Не аффилировано с Telegram.
