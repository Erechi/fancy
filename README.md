# ✦ Fancy

**Бесплатный генератор красивых адресов для Telegram Wallet.**
Считает на вашей видеокарте прямо в браузере — без сервера, без регистрации, с открытым кодом.

## Что это

Обычный адрес Telegram Wallet — 48 случайных символов. Fancy подбирает адрес, в котором есть **ваше слово**:

| Режим | Пример |
|---|---|
| В конце | `UQDJX1JURnv_PXgFgqZ9C8MCWxHq-nYOKVb_wsd1xcjb`**`GRAM`** |
| В начале | `UQ`**`Dog`**`A9SZk1kl0Xaj_f6BnzJ3IeccFPlHSd29e2Ug1HG…` |
| Начало + конец | `UQ`**`Dog`**`…`**`GRAM`** |

- **Считает видеокарта.** Сотни тысяч вариантов в секунду через WebGPU прямо во вкладке браузера.
- **Время видно сразу.** Пока вы печатаете, сайт показывает, сколько примерно ждать именно на вашем компьютере.
- **Все 24 слова создаются у вас.** Их нет ни у кого больше — ни у сервера, ни у автора.
- **Бесплатно.** Платите только сети за активацию кошелька: отправляете на новый адрес **0.1 GRAM**, комиссия ≈ 0.001 GRAM, остальное остаётся на вашем кошельке.

## Как пользоваться

1. Откройте [Releases](../../releases/latest) и скачайте **`Fancy.html`**.
2. Откройте файл двойным щелчком в **Chrome** или **Edge** последней версии. Сайт проверит видеокарту и замерит её скорость — при первом запуске это до 30 секунд.
3. Введите текст: **в конце**, **в начале** или **и там, и там**. Слева сразу видно, сколько ждать.
4. Нажмите **«Начать поиск»**. Окно можно свернуть, а вкладку не закрывайте. Когда адрес найдётся, прозвучит сигнал.
5. **«Оформить кошелёк»** → запишите **все 24 слова** по порядку на бумаге.
6. Отправьте **0.1 GRAM** на найденный адрес с любого кошелька и нажмите **«Сменить ключ на мои 24 слова»**.
7. Telegram → **Wallet** → **«Импортировать кошелёк»** → введите 24 слова. Готово.

> **Совет.** Для первого раза возьмите короткий текст (3–4 символа). Можно потренироваться в тестовой сети: «Дополнительно» → «Сеть» → Testnet.

## Сколько ждать

Поиск случайный: половина поисков заканчивается раньше медианы, 1 из 20 — примерно в 4 раза дольше. Каждый символ в точном регистре умножает время на 64, в любом регистре — примерно на 32.

Медиана для окончания на видеокарте **RTX 5070 Ti** в рекомендуемом режиме (~325 тыс. фраз/с):

| Символов | Любой регистр | Точный регистр |
|:-:|:-:|:-:|
| 3 | меньше секунды | меньше секунды |
| 4 | ~2 с | ~36 с |
| 5 | ~1 мин | ~38 мин |
| 6 | ~38 мин | ~40 ч |
| 7 | ~20 ч | ~3–4 месяца |
| 8 | ~4 недели | годы |

На вашем устройстве будет иначе — сайт сам замеряет скорость и пересчитывает таблицу.

## Требования

- **Браузер с WebGPU:** Chrome или Edge 113+ на Windows, macOS или Linux. Safari и Firefox — в свежих версиях, если WebGPU включён.
- **Видеокарта.** Без WebGPU поиск не запустится: сайт честно скажет об этом.
- **Интернет** нужен только на шаге смены ключа — чтобы проверить баланс и отправить транзакцию.
- **Нагрузка** настраивается: 25 / 50 / 75 / 100 %. По умолчанию 75 % — карта тише и холоднее, поиск лишь немного дольше.

## Безопасность и приватность

- **Нет сервера.** Fancy — один HTML-файл. Всё считается во вкладке браузера.
- **Что уходит в сеть.** Только на шаге оформления и только на публичный `toncenter.com`: адрес (проверить баланс) и подписанная транзакция развёртывания + смены ключа. Слова и приватные ключи не отправляются никогда.
- **Запрет на лишние соединения.** В файл встроен Content-Security-Policy: страница может обращаться только к `toncenter.com`.
- **Двойная проверка расчётов.** Перед поиском видеокарта и процессор считают одни и те же фразы — при любом расхождении видеокарта не используется. Каждая находка ещё раз пересчитывается на процессоре.
- **Ключ меняется в блокчейне.** После смены ключа слова 1–12 сами по себе ничего не подписывают — это свойство контракта, а не обещание. Транзакцию видно в любом эксплорере.
- **Где хранятся слова.** В `localStorage` вашего браузера, пока вы не удалите запись. После импорта в Wallet удалите её кнопкой «Удалить».

### Как проверить файл

1. **Контрольная сумма.** Рядом с `Fancy.html` в релизе лежит `Fancy.html.sha256`. Сравните:
   ```bash
   # Windows (PowerShell)
   Get-FileHash Fancy.html -Algorithm SHA256
   # macOS / Linux
   shasum -a 256 Fancy.html
   ```
2. **Файл собран из этого кода.** Релиз собирает GitHub Actions ([`.github/workflows/release.yml`](.github/workflows/release.yml)) — в логе сборки напечатана та же сумма.
3. **Соберите сами** (см. ниже) и сравните сумму с релизом.

## Как это устроено

Telegram Wallet использует контракт [**WalletTg**](https://github.com/ton-blockchain/tg-wallet-contract): у кошелька можно сменить ключ, а адрес остаётся прежним. Фраза из 24 слов делится на две половины:

| Слова | Откуда | Что делают |
|---|---|---|
| 1–12 | находит поиск | BIP39 → PBKDF2-HMAC-SHA512 (2048) → SLIP-10 ed25519 `m/44'/607'/0'` → публичный ключ → stateInit трамплина WalletTg → **адрес** |
| 13–24 | создаёт браузер | новый ключ кошелька |

1. **Поиск.** На видеокарте каждый поток берёт 128 бит случайной энтропии, строит 12 слов BIP39, считает PBKDF2 (≈4100 блоков SHA-512), SLIP-10, ed25519 и адрес, сравнивает с шаблоном. Шейдер — [`src/miner/vanity.wgsl`](src/miner/vanity.wgsl).
2. **Активация.** Одно external-сообщение: `stateInit` (развёртывание) + `ChangePublicKeyRequestE` (`0xFBBA99C8`), подписанное ключом слов 1–12, с доказательством `KEY_ROTATION`, подписанным ключом слов 13–24.
3. **Импорт.** Telegram Wallet по 24 словам восстанавливает и адрес (слова 1–12), и ключ (слова 13–24).

Реальная комиссия активации — около 0.0007 GRAM (замер на настоящем байткоде контракта в эмуляторе). 0.1 GRAM просим с запасом, остаток остаётся на кошельке.

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 22+.

```bash
git clone <ссылка на этот репозиторий>
cd fancy
npm ci
npm test          # сверка с эталонными библиотеками + эмулятор с живым контрактом
npm run build     # → dist/index.html (это и есть Fancy.html)
```

Режим разработки: `npm run dev` → http://127.0.0.1:5178.
